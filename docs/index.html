⚔️ Por que Go vs. Python & Docker?

Mineradores tradicionais em Python necessitam de máquina virtual, bibliotecas pesadas de bypass (`curl_cffi`) e containers Docker que gastam mais de 70 MB de RAM. O Kick Miner Go compila para um único executável estático que roda direto na VPS ou Windows.

🚀 Como Configurar e Rodar
1
Capture seu Bearer Token da Kick

Acesse kick.com, abra o F12 (Inspecionar) > aba Rede (Network). Filtre por api ou viewer e copie o cabeçalho Authorization: Bearer seu_token.

2
Configure o config.json

Copie o config.example.json para config.json e adicione o seu token e os streamers desejados: 

{
  "accounts": [
    {
      "username": "SeuUsuario",
      "bearerToken": "SEU_USER_ID|SEU_TOKEN_AQUI",
      "streamers": ["tftoddy", "faasii", "axtlol", "xdaren_"],
      "maxConcurrentStreams": 2
    }
  ]
}
3
Execute o Minerador

No Windows, dê duplo clique em iniciar.bat ou rode go run .. Para VPS Linux, basta rodar o binário compilado ./kick-miner-linux.
