🚀 Como configurar
1
Copie o token Bearer da Kick

No site da Kick, abra as ferramentas de rede do navegador e copie o cabeçalho Authorization. Não cole um token real nesta página.

2
Preencha o config.json local

Use o exemplo abaixo só como formato. O token mostrado é um marcador, nunca uma credencial.

{
  "accounts": [
    {
      "username": "SeuUsuario",
      "bearerToken": "SEU_USER_ID|SEU_TOKEN_AQUI",
      "streamers": ["canal-exemplo"],
      "maxConcurrentStreams": 2
    }
  ]
}
3
Rode o minerador na sua máquina

No Windows, use iniciar.bat ou go run .. Na VPS Linux, rode o binário compilado. Esta página não envia comandos.
